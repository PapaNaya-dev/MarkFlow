MarkFlow Tutorial

Selamat datang di MarkFlow! Panduan ini akan membantu Anda menguasai Markdown dalam waktu singkat.

1. Membuat Judul (Headers)

Gunakan simbol # diikuti spasi di awal baris.

# Judul Besar (H1)
## Judul Sedang (H2)
### Judul Kecil (H3)

2. Format Teks (Emphasis)

Gunakan bintang atau underscore untuk membuat teks lebih menonjol.

**Teks Tebal** (Bold)
*Teks Miring* (Italic)
~~Teks Dicoret~~ (Strikethrough)

3. Kutipan (Blockquotes)

Gunakan simbol > untuk membuat kutipan atau catatan penting.

> Ini adalah kutipan inspiratif atau catatan penting.

4. Daftar (Lists)

Membuat daftar terurut atau tidak terurut sangat mudah.

- Item pertama
- Item kedua
  - Sub-item

1. Langkah satu
2. Langkah dua

5. Flowchart & Diagram (Mermaid)

Gunakan blok kode dengan identitas mermaid untuk membuat diagram alir otomatis.

```mermaid
graph TD;
    A[Mulai] --> B{Pilihan};
    B -- Ya --> C[Selesai];
    B -- Tidak --> D[Ulangi];
    D --> B;
```
Tip: Diagram akan langsung dirender secara visual di panel kanan MarkFlow!

6. Shortcut Keyboard

  • Ctrl + O : Buka File
  • Ctrl + S : Simpan File
  • Ctrl + P : Export ke PDF
