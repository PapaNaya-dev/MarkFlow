Getting Started with MarkFlow

MarkFlow is a minimalist Markdown editor designed for speed and elegance.

Keyboard Shortcuts

  • Ctrl + O: Open Markdown file
  • Ctrl + S: Save changes
  • Ctrl + P: Export to PDF

Mermaid Diagrams

Render flowcharts and graphs by using the mermaid language identifier in code blocks:

```mermaid
graph TD;
    A-->B;
    A-->C;
    B-->D;
    C-->D;
```

Syncing Preview

The preview on the right updates automatically as you type in the editor.
